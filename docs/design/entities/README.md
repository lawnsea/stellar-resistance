The game world is made up of planets. Each planet consists of one or more regions, and each region contains pops: the groups of people who live and work there. Factions are organized groups that act in the game world through their cells, each of which is based in a region and has pops as members. Each planet has a planetary faction, and by default a region's pops belong to that faction's cell in the region.
