The game world is made up of planets. Each planet consists of one or more regions, and each region contains pops: the groups of people who live and work there. Factions are organized groups that act in the game world through their cells. Each cell is based in a region and holds its member pops. Each planet has a planetary faction, which owns a regional cell in each of its regions; the regional cell holds every pop in the region that isn't in another cell.
