# Faction

Factions are organized groups that act in the game world.

## API

Exported from `@stellar-resistance/engine`.

### `Faction`

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Unique identifier |
| `name` | `string` | Display name |

### `createFaction(fields: Faction): Faction`

Creates a faction.
